# Análisis de resultados

Después de realizar las ejecuciones, registrar por semilla: aptitud, cobertura ponderada, número de regiones cubiertas, validez, parámetros y tiempo. Comparar la evolución, el efecto de las restricciones y las diferencias entre ejecuciones.

Una puntuación alta no demuestra optimalidad global. La validez espacial se informa separada de la cobertura. No afirmar que la solución es óptima; describir la evidencia disponible y las limitaciones del modelo simplificado.
